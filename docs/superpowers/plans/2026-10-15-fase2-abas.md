# Orbit 2.0 — Fase 2 (Abas do 1.0 + pílula viva) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Trazer para a ilha as abas Controles, Hoje, Stats, Mercado, Notícias e Claude (portando o Orbit 1.0), fazer a pílula mostrar atividade real (música, Pomodoro, Claude) e alertas, e fechar as pendências da revisão da fase 1.

**Architecture:** Cada aba é uma pasta `Orbit/Tabs/<Nome>/` com `XViewModel : TabViewModel` + `XView.xaml`, registrada no construtor do `IslandViewModel` via `Register(...)` e ordenada por `IslandViewModel.TabOrder`. Três serviços rodam sempre, orientados a evento, e alimentam a pílula pelo `IslandViewModel`: `NowPlayingViewModel` (SMTC), `PomodoroViewModel` (timer só quando rodando) e o `ClaudeHookServer` (named pipe). Abas com rede usam um "portão de frescor" (`Freshness.IsStale`): ao abrir a aba só busca se o dado estiver velho, e o timer só roda com a aba visível. Alertas passam por um ponto único, `IslandViewModel.Notify(peek, sound)`.

**Tech Stack:** .NET 10 WPF, CommunityToolkit.Mvvm 8.4.1, Serilog, Microsoft.Toolkit.Uwp.Notifications 7.1.3 (toast), NAudio.Wasapi 2.2.1 (volume), System.Diagnostics.PerformanceCounter (GPU), WinRT (`Windows.Media.Control`, `Windows.Devices.Radios`).

```csharp
using System;
using System.Windows.Media;

namespace Orbit.Services;

// Anel de progresso: o contorno nativo de uma Ellipse cortado via StrokeDashArray
// (no 1.0, Path+ArcSegment perto de 360° renderizava facetado nesta máquina).
// Valores de StrokeDashArray são múltiplos da espessura do traço (convenção do WPF).
// Na view, a Ellipse leva RotateTransform -90 pra começar no topo.
public static class Ring
{
    public static DoubleCollection DashArray(double progress, double diameter, double strokeThickness)
    {
        double p = Math.Clamp(progress, 0.0, 1.0);
        double circumference = Math.PI * diameter / strokeThickness;
        return new DoubleCollection { p * circumference, (1 - p) * circumference };
    }
}
```

```csharp
using System;
using System.IO;
using System.Threading;
using System.Windows;
using Orbit.Island;
using Orbit.Services;
using Serilog;

namespace Orbit;

public partial class App : Application
{
    private Mutex? _mutex;
    private IslandWindow? _island;

    protected override void OnStartup(StartupEventArgs e)
    {
        base.OnStartup(e);

        // Instância única ANTES do log: a 2ª instância não pode escrever no log da 1ª.
        var mutex = new Mutex(initiallyOwned: true, "Orbit2_SingleInstance", out bool isNew);
        if (!isNew)
        {
            mutex.Dispose();
            Shutdown();
            return;
        }
        _mutex = mutex;

        Directory.CreateDirectory(SettingsStore.LogsDir);
        Log.Logger = new LoggerConfiguration()
            .MinimumLevel.Information()
            .WriteTo.File(
                Path.Combine(SettingsStore.LogsDir, "orbit-.txt"),
                rollingInterval: RollingInterval.Hour,
                retainedFileCountLimit: 168,
                outputTemplate: "{Timestamp:HH:mm:ss.fff} [{Level:u3}] {Message:lj}{NewLine}{Exception}")
            .CreateLogger();

        // Loga e mantém a ilha viva (spec §8).
        DispatcherUnhandledException += (_, args) =>
        {
            Log.Error(args.Exception, "Exceção não tratada no dispatcher");
            args.Handled = true;
        };
        AppDomain.CurrentDomain.UnhandledException += (_, args) =>
            Log.Fatal(args.ExceptionObject as Exception, "Exceção fatal não tratada");

        Log.Information("Orbit 2 iniciado");
        try
        {
            var settings = SettingsStore.Load();
            Accent.Start(() => settings.AccentOverride);
            _island = new IslandWindow(new IslandViewModel(settings));
            _island.Show();
        }
        catch (Exception ex)
        {
            Log.Fatal(ex, "Falha no startup");
            _island?.ReleaseResources();
            Shutdown(1);
        }
    }

    protected override void OnExit(ExitEventArgs e)
    {
        _island?.ReleaseResources();
        _mutex?.ReleaseMutex();
        _mutex?.Dispose();
        Log.Information("Orbit 2 encerrando");
        Log.CloseAndFlush();
        base.OnExit(e);
    }
}
```

```csharp
public sealed partial class IslandViewModel : ObservableObject
{
    // Ordem fixa das abas no painel. Ids ainda não registrados são pulados.
    public static readonly string[] TabOrder =
        { "controles", "hoje", "stats", "mercado", "noticias", "claude", "energia", "ajustes" };

    private readonly IslandMachine _machine = new();
    private readonly OrbitSettings _settings;
    private readonly List<TabViewModel> _allTabs = new();

    public ObservableCollection<TabViewModel> Tabs { get; } = new();

    [ObservableProperty] private TabViewModel? _selectedTab;
    [ObservableProperty] private IslandMode _mode = IslandMode.Repouso;
    [ObservableProperty] private string _activityText = "";
    [ObservableProperty] private Peek? _peek;

    public IslandViewModel(OrbitSettings settings)
    {
        _settings = settings;
        // Sem DI: abas e serviços de fundo são criados aqui na mão.
        Register(new EnergiaViewModel());
        Register(new AjustesViewModel(settings, () => _allTabs, ApplyTabVisibility));
        // novas abas/serviços entram acima desta linha
        ApplyTabVisibility();
        SelectedTab = Tabs.FirstOrDefault(t => t.Id == settings.LastTab) ?? Tabs.FirstOrDefault();

    private void Register(TabViewModel tab) => _allTabs.Add(tab);

    // Ids visíveis na ordem de TabOrder. "ajustes" nunca some (senão não dá pra reverter).
    public static List<string> VisibleIds(ICollection<string> registered, ICollection<string> hidden) =>
        TabOrder.Where(id => registered.Contains(id) && (id == "ajustes" || !hidden.Contains(id))).ToList();

    // Sincroniza Tabs com as preferências sem recriar a coleção (a aba aberta continua aberta).
    public void ApplyTabVisibility()
    {
        var ids = VisibleIds(_allTabs.Select(t => t.Id).ToList(), _settings.HiddenTabs);
        for (int i = Tabs.Count - 1; i >= 0; i--)
            if (!ids.Contains(Tabs[i].Id)) Tabs.RemoveAt(i);
        for (int i = 0; i < ids.Count; i++)
            if (i >= Tabs.Count || Tabs[i].Id != ids[i])
                Tabs.Insert(i, _allTabs.First(t => t.Id == ids[i]));
        if (SelectedTab is null || !Tabs.Contains(SelectedTab)) SelectedTab = Tabs.FirstOrDefault();
    }

    partial void OnSelectedTabChanged(TabViewModel? oldValue, TabViewModel? newValue)
    {
        if (Mode == IslandMode.Expandida)
        {
            SafeSetActive(oldValue, false);
            SafeSetActive(newValue, true);
        }
        if (newValue is not null && newValue.Id != _settings.LastTab)
        {
            _settings.LastTab = newValue.Id;
            SettingsStore.Save(_settings);
        }
    }

    public void Expand() { _machine.Expand(); Refresh(); }
    public void Collapse() { _machine.Collapse(); Refresh(); }
    public void SetFullscreen(bool on) { _machine.SetFullscreen(on); Refresh(); }
    public void SetActivity(ActivityKind kind, string? text) { _machine.SetActivity(kind, text); Refresh(); }
    public void RaisePeek(Peek peek) { _machine.RaisePeek(peek); Refresh(); }
    public void PeekExpired() { _machine.PeekDone(); Refresh(); }

    // Ponto único de alerta dos serviços/abas. Em tela cheia com a preferência ligada vira
    // toast do Windows; senão é peek na pílula (com bip curto, já que o peek é silencioso).
    public void Notify(Peek peek, bool sound)
    {
        if (ShouldToast(_machine.Fullscreen, _settings.AlertsAsToastInFullscreen))
        {
            ToastNotifier.Notify(peek.Title, peek.Detail ?? "", sound);
            return;
        }
        if (sound && !_machine.Fullscreen) SystemSounds.Asterisk.Play();
        RaisePeek(peek);

        if (tab is not null) SelectedTab = tab;
        Expand();

    public void OpenPeekTab()
    {

        _machine.PeekDone();
        if (tabId is null) Expand();
        else OpenTab(tabId);
    }

        ActivityText = _machine.ActivityText ?? "";
        Peek = _machine.CurrentPeek;
        Mode = _machine.Mode; // por último: a janela reage a Mode e já lê Peek/ActivityText novos
        if (before != IslandMode.Expandida && Mode == IslandMode.Expandida) SafeSetActive(SelectedTab, true);
        if (before == IslandMode.Expandida && Mode != IslandMode.Expandida) SafeSetActive(SelectedTab, false);
    }

    // Uma aba quebrada não pode derrubar a ilha.
    public static void SafeSetActive(TabViewModel? tab, bool active)
    {
        if (tab is null) return;
        try
        {
            tab.SetActive(active);
        }
        catch (Exception ex)
        {
            Log.Error(ex, "Aba {Tab} falhou em SetActive({Active})", tab.Id, active);
        }
    }
```

```csharp
                     .Where(t => t.Id != "ajustes")
```

```csharp
    // Uma bolinha por ciclo até a pausa longa; preenchida = ciclo de foco concluído.
    public ObservableCollection<bool> CycleDots { get; } = new();

    private int EffectiveCycles => Math.Max(1, _cyclesUntilLongBreak);

    // phaseChanged(novaFase, minutos): a ilha transforma em alerta.
    public PomodoroViewModel(int focusMinutes, int shortBreakMinutes, int longBreakMinutes,
        int cyclesUntilLongBreak, Action<PomodoroPhase, int> phaseChanged)
    {
        _focusMinutes = focusMinutes;
        _shortBreakMinutes = shortBreakMinutes;
        _longBreakMinutes = longBreakMinutes;
        _cyclesUntilLongBreak = cyclesUntilLongBreak;
        _phaseChanged = phaseChanged;
        _timer.Tick += (_, _) => Tick();
        EnterPhase(PomodoroPhase.Focus);
    }

    // Novas durações valem a partir da próxima fase; nº de ciclos vale já.
    public void UpdateConfig(int focusMinutes, int shortBreakMinutes, int longBreakMinutes, int cyclesUntilLongBreak)
    {
        _focusMinutes = focusMinutes;
        _shortBreakMinutes = shortBreakMinutes;
        _longBreakMinutes = longBreakMinutes;
        _cyclesUntilLongBreak = cyclesUntilLongBreak;
        RebuildCycleDots();
        // Parado no começo de uma fase: já mostra a duração nova.
        if (!IsRunning && _remaining == _phaseTotal) EnterPhase(_phase);
    }

    [RelayCommand]
    private void Toggle()
    {
        if (_timer.IsEnabled) _timer.Stop();
        else _timer.Start();
        IsRunning = _timer.IsEnabled;
        PlayGlyph = IsRunning ? "\uE769" : "\uE768";
        UpdateActivity();
    }

    [RelayCommand]
    private void Reset()
    {
        _timer.Stop();
        IsRunning = false;
        PlayGlyph = "\uE768";
        _completedCycles = 0;
        EnterPhase(PomodoroPhase.Focus);
    }

    private void Tick()
    {
        _remaining = _remaining.Subtract(TimeSpan.FromSeconds(1));
        if (_remaining <= TimeSpan.Zero)
        {
            var (next, cycles) = NextPhase(_phase, _completedCycles, EffectiveCycles);
            _completedCycles = cycles;
            EnterPhase(next);
            _phaseChanged(next, PhaseMinutes(next));
        }
        UpdateDisplay();
    }

    private void EnterPhase(PomodoroPhase phase)
    {
        _phase = phase;
        Mode = PhaseLabel(phase);
        _phaseTotal = TimeSpan.FromMinutes(PhaseMinutes(phase));
        _remaining = _phaseTotal;
        RebuildCycleDots();
        UpdateDisplay();
    }

    private int PhaseMinutes(PomodoroPhase phase) => phase switch
    {
        PomodoroPhase.Focus => _focusMinutes,
        PomodoroPhase.ShortBreak => _shortBreakMinutes,
        _ => _longBreakMinutes,
    };

    private void RebuildCycleDots()
    {
        CycleDots.Clear();
        for (int i = 0; i < EffectiveCycles; i++) CycleDots.Add(i < _completedCycles);
    }

    private void UpdateDisplay()
    {
        Display = $"{(int)_remaining.TotalMinutes:00}:{_remaining.Seconds:00}";
        double progress = _phaseTotal.TotalSeconds > 0 ? _remaining.TotalSeconds / _phaseTotal.TotalSeconds : 0;
        RingDashArray = Ring.DashArray(progress, RingDiameter, RingStroke);
        UpdateActivity();
    }

    private void UpdateActivity() => ActivityText = BuildActivity(IsRunning, Mode, Display);

    // --- Lógica pura testável ---

    public static string? BuildActivity(bool running, string mode, string display) =>
        running ? $"{mode} · {display}" : null;

    public static string PhaseLabel(PomodoroPhase phase) => phase switch
    {
        PomodoroPhase.ShortBreak => "Pausa",
        PomodoroPhase.LongBreak => "Pausa longa",
        _ => "Foco",
    };

    public static (PomodoroPhase Phase, int CompletedCycles) NextPhase(
        PomodoroPhase phase, int completedCycles, int cyclesUntilLongBreak)
    {
        int total = Math.Max(1, cyclesUntilLongBreak);
        if (phase != PomodoroPhase.Focus) return (PomodoroPhase.Focus, completedCycles);
        int done = completedCycles + 1;
        return done >= total ? (PomodoroPhase.LongBreak, 0) : (PomodoroPhase.ShortBreak, done);
    }
```

```csharp
            var dtos = JsonSerializer.Deserialize<List<TodoDto>>(File.ReadAllText(path));
            return dtos?.Select(d => new TodoItem(d.Text ?? "", d.Done)).ToList() ?? new();
        }
        catch

        }
    }

    public static void Save(IEnumerable<TodoItem> items, string path)
    {
        try
        {
            Directory.CreateDirectory(Path.GetDirectoryName(path)!);
            var dtos = items.Select(i => new TodoDto(i.Text, i.Done)).ToList();
            File.WriteAllText(path, JsonSerializer.Serialize(dtos, WriteOptions));
        }
        catch
        {
            // disco cheio / sem permissão: não vale crashar a ilha por causa de to-do.
        }
    }
}
```

```csharp
    public override string Title => "Hoje";

    public ObservableCollection<TodoItem> Todos { get; } = new();

    [ObservableProperty] private string _time = "";
    [ObservableProperty] private string _date = "";
    [ObservableProperty] private string _newTodo = "";
    [ObservableProperty] private string _todoCounter = "0/0";

        Pomodoro = pomodoro;
        _todosPath = todosPath;

    }
```

```csharp
public sealed partial class NowPlayingViewModel : ObservableObject

    private readonly NowPlayingWatcher _watcher = new();

    [ObservableProperty] private bool _hasSession;
    [ObservableProperty] private string _title = "";
    [ObservableProperty] private string _subtitle = "";
    [ObservableProperty] private BitmapImage? _thumbnail;
    [ObservableProperty] private string _playPauseGlyph = "\uE768";
    [ObservableProperty] private string? _activityText;

    public NowPlayingViewModel()
    {
        // O evento vem de thread do WinRT: volta pro dispatcher antes de mexer em propriedades.
        _watcher.SessionChanged += info => Application.Current?.Dispatcher.BeginInvoke(() => Apply(info));
    }

    public void Start() => _watcher.Start();

    private void Apply(NowPlayingInfo? info)
    {
        HasSession = info != null;
        ActivityText = BuildActivity(info);
        if (info == null)
        {
            Title = "";
            Subtitle = "";
            PlayPauseGlyph = PlayPauseGlyphFor(false);
            Thumbnail = null;
            return;
        }
        Title = DisplayTitle(info.Title);
        Subtitle = info.Artist ?? "";
        PlayPauseGlyph = PlayPauseGlyphFor(info.IsPlaying);
        Thumbnail = info.Thumbnail == null ? null : BuildThumbnail(info.Thumbnail);
    }

    private static BitmapImage? BuildThumbnail(byte[] bytes)
    {
        try
        {
            using var ms = new MemoryStream(bytes);
            var bmp = new BitmapImage();
            bmp.BeginInit();
            bmp.CacheOption = BitmapCacheOption.OnLoad;
            bmp.DecodePixelWidth = 128; // capa é exibida em 64px: não guarda a imagem cheia na memória
            bmp.StreamSource = ms;
            bmp.EndInit();
            bmp.Freeze();
            return bmp;
        }
        catch
        {
            return null; // formato não suportado: a view mostra o glifo de música
        }
    }

    public static string DisplayTitle(string? title) =>
        string.IsNullOrWhiteSpace(title) ? "Tocando…" : title;

    public static string PlayPauseGlyphFor(bool isPlaying) => isPlaying ? "\uE769" : "\uE768";

    // Texto da pílula: só enquanto toca (pausado não ocupa a pílula).
    public static string? BuildActivity(NowPlayingInfo? info)
    {
        if (info is not { IsPlaying: true }) return null;
        var title = DisplayTitle(info.Title);
        return string.IsNullOrWhiteSpace(info.Artist) ? $"▶  {title}" : $"▶  {title} · {info.Artist}";
    }

    [RelayCommand] private Task PlayPause() => _watcher.PlayPauseAsync();
```

```csharp
using System;
using NAudio.CoreAudioApi;
using Serilog;

namespace Orbit.Services;

// Volume mestre da saída padrão (Core Audio via NAudio.Wasapi). Criado só com a aba
// Controles visível; Dispose solta o callback do Windows.
// ponytail: troca de dispositivo padrão com a aba aberta não é seguida; reabrir a aba resolve.
public sealed class Volume : IDisposable
{
    private readonly MMDeviceEnumerator _enumerator = new();
    private readonly MMDevice? _device;

    // (0–100, mudo). Vem de thread do Windows — quem assina volta pro dispatcher.
    public event Action<double, bool>? Changed;

    public Volume()
    {
        try
        {
            _device = _enumerator.GetDefaultAudioEndpoint(DataFlow.Render, Role.Multimedia);
            _device.AudioEndpointVolume.OnVolumeNotification += OnNotify;
        }
        catch (Exception ex)
        {
            Log.Warning(ex, "Sem dispositivo de áudio padrão");
        }
    }

    public bool Available => _device is not null;
    public double Percent => _device is null ? 0 : ToPercent(_device.AudioEndpointVolume.MasterVolumeLevelScalar);
    public bool Muted => _device?.AudioEndpointVolume.Mute ?? false;

    public void SetPercent(double percent)
    {
        if (_device is not null) _device.AudioEndpointVolume.MasterVolumeLevelScalar = ToScalar(percent);
    }

    public void ToggleMute()
    {
        if (_device is not null) _device.AudioEndpointVolume.Mute = !_device.AudioEndpointVolume.Mute;
    }

    private void OnNotify(AudioVolumeNotificationData data) => Changed?.Invoke(ToPercent(data.MasterVolume), data.Muted);

    public static double ToPercent(float scalar) => Math.Round(Math.Clamp(scalar, 0f, 1f) * 100);
    public static float ToScalar(double percent) => (float)(Math.Clamp(percent, 0, 100) / 100);

    public void Dispose()
    {
        if (_device is not null)
        {
            _device.AudioEndpointVolume.OnVolumeNotification -= OnNotify;
            _device.Dispose();
        }
        _enumerator.Dispose();
    }
}
```

```csharp
using System;
using System.Linq;
using System.Threading.Tasks;
using Serilog;
using Windows.Devices.Radios;

namespace Orbit.Services;

// Wi‑Fi/Bluetooth via Windows.Devices.Radios (API pública). Se o Windows negar acesso
// a um app desktop, devolve null e a aba abre a página do Configurações no lugar.
public static class Radios
{
    // null = rádio inexistente ou acesso negado.
    public static async Task<bool?> IsOnAsync(RadioKind kind)
    {
        var radio = await FindAsync(kind);
        return radio is null ? null : radio.State == RadioState.On;
    }

    // Novo estado, ou null se não deu (sem rádio/sem permissão).
    public static async Task<bool?> ToggleAsync(RadioKind kind)
    {
        var radio = await FindAsync(kind);
        if (radio is null) return null;
        var target = radio.State == RadioState.On ? RadioState.Off : RadioState.On;
        try
        {
            var result = await radio.SetStateAsync(target);
            if (result != RadioAccessStatus.Allowed)
            {
                Log.Warning("Rádio {Kind}: {Result}", kind, result);
                return null;
            }
            return target == RadioState.On;
        }
        catch (Exception ex)
        {
            Log.Warning(ex, "Falha ao alternar rádio {Kind}", kind);
            return null;
        }
    }

    private static async Task<Radio?> FindAsync(RadioKind kind)
    {
        try
        {
            if (await Radio.RequestAccessAsync() != RadioAccessStatus.Allowed) return null;
            return (await Radio.GetRadiosAsync()).FirstOrDefault(r => r.Kind == kind);
        }
        catch (Exception ex)
        {
            Log.Warning(ex, "Rádios indisponíveis");
            return null;
        }
    }
}
```

```csharp
using System;
using System.Runtime.InteropServices;
using Microsoft.Win32;

namespace Orbit.Services;

// Modo escuro do Windows (apps + sistema) pelo registro do usuário + aviso aos apps abertos.
public static class DarkMode
{
    private const string Key = @"Software\Microsoft\Windows\CurrentVersion\Themes\Personalize";
    private static readonly IntPtr HWND_BROADCAST = new(0xFFFF);
    private const uint WM_SETTINGCHANGE = 0x001A, SMTO_ABORTIFHUNG = 0x0002;

    public static bool IsDark()
    {
        using var k = Registry.CurrentUser.OpenSubKey(Key);
        return k?.GetValue("AppsUseLightTheme") is int v && v == 0;
    }

    public static int RegistryValue(bool dark) => dark ? 0 : 1;

    // Bloqueia até ~200 ms por janela travada (SMTO_ABORTIFHUNG pula as travadas):
    // chame fora da UI thread.
    public static void Set(bool dark)
    {
        using (var k = Registry.CurrentUser.CreateSubKey(Key))
        {
            k.SetValue("AppsUseLightTheme", RegistryValue(dark), RegistryValueKind.DWord);
            k.SetValue("SystemUsesLightTheme", RegistryValue(dark), RegistryValueKind.DWord);
        }
        SendMessageTimeout(HWND_BROADCAST, WM_SETTINGCHANGE, IntPtr.Zero, "ImmersiveColorSet",
            SMTO_ABORTIFHUNG, 200, out _);
    }

    [DllImport("user32.dll", CharSet = CharSet.Unicode)]
    private static extern IntPtr SendMessageTimeout(IntPtr hWnd, uint msg, IntPtr wParam, string lParam,
        uint fuFlags, uint uTimeout, out IntPtr lpdwResult);
}
```

```csharp
using System;
using System.Collections.Generic;
using System.Diagnostics;
using System.Linq;
using Serilog;

namespace Orbit.Services;

// Uso de GPU como o Gerenciador de Tarefas: soma da "Utilization Percentage" dos motores
// 3D (contadores "GPU Engine"). Só é lido com a aba Stats aberta.
public sealed class GpuStats : IDisposable
{
    private readonly Dictionary<string, PerformanceCounter> _counters = new();
    private bool _warned;

    // ponytail: relista as instâncias a cada leitura (processos entram/saem) — custa alguns ms
    // a cada 2 s com a aba aberta. Cachear a lista por alguns ciclos se pesar.
    public double Read()
    {
        try
        {
            var names = new PerformanceCounterCategory("GPU Engine").GetInstanceNames()
                .Where(n => n.Contains("engtype_3D", StringComparison.Ordinal))
                .ToHashSet();
            foreach (var gone in _counters.Keys.Where(k => !names.Contains(k)).ToList())
            {
                _counters[gone].Dispose();
                _counters.Remove(gone);
            }
            var samples = new List<float>();
            foreach (var name in names)
            {
                if (!_counters.TryGetValue(name, out var c))
                {
                    c = new PerformanceCounter("GPU Engine", "Utilization Percentage", name, readOnly: true);
                    _counters[name] = c;
                }
                samples.Add(c.NextValue()); // 1ª leitura de um contador novo é 0; corrige no tick seguinte
            }
            return Aggregate(samples);
        }
        catch (Exception ex)
        {
            if (!_warned) Log.Warning(ex, "Contadores de GPU indisponíveis");
            _warned = true;
            return 0;
        }
    }

    public static double Aggregate(IEnumerable<float> engine3DSamples) =>
        Math.Clamp(engine3DSamples.Sum(), 0, 100);

    public void Dispose()
    {
        foreach (var c in _counters.Values) c.Dispose();
        _counters.Clear();
    }
}
```

```csharp
using System;
using System.Globalization;
using System.Net.NetworkInformation;

namespace Orbit.Services;

// Taxa de rede ↓/↑ somando as interfaces ativas (menos loopback), por delta entre leituras.
public sealed class NetStats
{
    private static readonly CultureInfo Pt = new("pt-BR");
    private long _rx, _tx;
    private DateTime _at;

    public (double DownBps, double UpBps) Read()
    {
        long rx = 0, tx = 0;
        foreach (var ni in NetworkInterface.GetAllNetworkInterfaces())
        {
            if (ni.OperationalStatus != OperationalStatus.Up || ni.NetworkInterfaceType == NetworkInterfaceType.Loopback) continue;
            var s = ni.GetIPStatistics();
            rx += s.BytesReceived;
            tx += s.BytesSent;
        }
        var now = DateTime.UtcNow;
        double secs = (now - _at).TotalSeconds;
        var result = _at == default ? (0d, 0d) : (Rate(_rx, rx, secs), Rate(_tx, tx, secs));
        _rx = rx;
        _tx = tx;
        _at = now;
        return result;
    }

    // Aba fechada: a próxima leitura recomeça (sem média do tempo parado).
    public void Reset() => _at = default;

    public static double Rate(long before, long after, double seconds) =>
        seconds <= 0 || after < before ? 0 : (after - before) / seconds;

    public static string Format(double bytesPerSec) =>
        bytesPerSec >= 1_048_576 ? string.Format(Pt, "{0:0.0} MB/s", bytesPerSec / 1_048_576)
        : bytesPerSec >= 1024 ? string.Format(Pt, "{0:0} KB/s", bytesPerSec / 1024)
        : string.Format(Pt, "{0:0} B/s", bytesPerSec);
}
```

```csharp
        CpuText = $"{s.CpuPercent:0}%";
        CpuRing = Ring.DashArray(s.CpuPercent / 100, RingDiameter, RingStroke);
        RamText = $"{s.Ram.Percent:0}%";

        double gpu = _gpu.Read();
        GpuText = $"{gpu:0}%";

        var (down, up) = _net.Read();

                try { list.Add((p.ProcessName, p.WorkingSet64)); }
                catch { /* processo saiu no meio da leitura */ }
            }

        return list;

    public static List<(string Name, long Bytes)> TopByMemory(IEnumerable<(string Name, long Bytes)> procs, int n) =>
        procs.GroupBy(p => p.Name, StringComparer.OrdinalIgnoreCase)
            .Select(g => (Name: g.First().Name, Bytes: g.Sum(x => x.Bytes)))
            .OrderByDescending(x => x.Bytes)
            .Take(n)
            .ToList();

            : string.Format(Pt, "{0:0} MB", bytes / (double)(1L << 20));
```

```csharp
namespace Orbit.Island;

// 0..1 → GridLength em estrelas. ConverterParameter="rest" devolve o complemento (1 - f).
public sealed class FractionToStar : IValueConverter
{
    public object Convert(object value, Type targetType, object parameter, CultureInfo culture)
    {
        double f = value is double d ? Math.Clamp(d, 0, 1) : 0;
        if (parameter as string == "rest") f = 1 - f;
        return new GridLength(Math.Max(f, 0.0001), GridUnitType.Star);
    }

    public object ConvertBack(object value, Type targetType, object parameter, CultureInfo culture) =>
        throw new NotSupportedException();
}
```

```csharp
// Portado dos tiles Crypto/Exchange do 1.0, juntos numa aba. Preços a cada 60 s (o 1.0
// fazia cripto a cada 30 s; 60 s é mais gentil com o limite do CoinGecko) e sparklines a

public sealed partial class MercadoViewModel : TabViewModel
{
    private static readonly TimeSpan PricesEvery = TimeSpan.FromSeconds(60);
    private static readonly TimeSpan SparksEvery = TimeSpan.FromMinutes(5);

    private readonly ApiService _api;
    private readonly OrbitSettings _settings;
    private readonly DispatcherTimer _prices = new() { Interval = PricesEvery };
    private readonly DispatcherTimer _sparks = new() { Interval = SparksEvery };
    private DateTime? _pricesAt, _sparksAt;

    public override string Id => "mercado";
    public override string Title => "Mercado";

    public ObservableCollection<MarketRow> Rows { get; } = new();
    public ObservableCollection<MarketOption> CryptoOptions { get; } = new();
    public ObservableCollection<MarketOption> CurrencyOptions { get; } = new();

    [ObservableProperty] private bool _isEditing;

    public MercadoViewModel(ApiService api, OrbitSettings settings)
    {
        _api = api;
        _settings = settings;
        _prices.Tick += async (_, _) => await RefreshPricesAsync();
        _sparks.Tick += async (_, _) => await RefreshSparksAsync();
        BuildRows();
    }

    public override void SetActive(bool active)
    {
        if (!active)
        {
            _prices.Stop();
            _sparks.Stop();
            IsEditing = false;
            return;
        }
        var now = DateTime.Now;
        if (Freshness.IsStale(_pricesAt, PricesEvery, now)) _ = RefreshPricesAsync();
        if (Freshness.IsStale(_sparksAt, SparksEvery, now)) _ = RefreshSparksAsync();
        _prices.Start();
        _sparks.Start();
    }

    private void BuildRows()
    {
        Rows.Clear();
        foreach (var item in _settings.MarketCryptos.Select(MarketCatalog.FindCrypto).OfType<MarketCatalogItem>())
            Rows.Add(new MarketRow(item.Id, item.Glyph, item.ColorHex, item.Name, MarketKind.Crypto));
        foreach (var item in _settings.MarketCurrencies.Select(MarketCatalog.FindCurrency).OfType<MarketCatalogItem>())
            Rows.Add(new MarketRow(item.Id, item.Glyph, item.ColorHex, item.Name, MarketKind.Currency));
    }

    private async Task RefreshPricesAsync()
    {
        var cryptoRows = Rows.Where(r => r.Kind == MarketKind.Crypto).ToList();
        var currencyRows = Rows.Where(r => r.Kind == MarketKind.Currency).ToList();
        var crypto = await _api.GetCryptoPricesAsync(cryptoRows.Select(r => r.Id));
        var fx = await _api.GetExchangePricesAsync(currencyRows.Select(r => r.Id));
        if (crypto is not null)
            foreach (var row in cryptoRows)
                if (crypto.TryGetValue(row.Id, out var p))
                {
                    row.Price = FormatUsd(p.Price);
                    (row.Change, row.ChangeColor) = ChangeIndicator.Format(p.Change);
                }
        if (fx is not null)
            foreach (var row in currencyRows)
                if (fx.TryGetValue(row.Id, out var p))
                {
                    row.Price = "R$ " + p.Price.ToString("0.00", CultureInfo.InvariantCulture);
                    (row.Change, row.ChangeColor) = ChangeIndicator.Format(p.Change, 2);
                }
        if (crypto is not null || fx is not null) _pricesAt = DateTime.Now;
    }

    // ponytail: 1 chamada por cripto; limitar ao top-N se bater no rate limit.
    private async Task RefreshSparksAsync()
    {
        foreach (var row in Rows.Where(r => r.Kind == MarketKind.Crypto).ToList())
            row.SetSparkline(await _api.GetSparklineAsync(row.Id));
        _sparksAt = DateTime.Now;
    }

    [RelayCommand]
    private void Edit()
    {
        Fill(CryptoOptions, MarketCatalog.Cryptos, _settings.MarketCryptos);
        Fill(CurrencyOptions, MarketCatalog.Currencies, _settings.MarketCurrencies);
        IsEditing = true;
    }

    [RelayCommand]
    private void CancelEdit() => IsEditing = false;

    [RelayCommand]
    private void SaveEdit()
    {
        _settings.MarketCryptos = CryptoOptions.Where(o => o.Selected).Select(o => o.Id).ToList();
        _settings.MarketCurrencies = CurrencyOptions.Where(o => o.Selected).Select(o => o.Id).ToList();
        SettingsStore.Save(_settings);
        BuildRows();
        _pricesAt = _sparksAt = null;
        _ = RefreshPricesAsync();
        _ = RefreshSparksAsync();
        IsEditing = false;
    }

    private static void Fill(ObservableCollection<MarketOption> target, IReadOnlyList<MarketCatalogItem> catalog, IReadOnlyList<string> saved)
    {
        target.Clear();
        var byId = catalog.ToDictionary(c => c.Id);
        foreach (var id in OrderCatalog(catalog.Select(c => c.Id).ToList(), saved))
            target.Add(new MarketOption(byId[id], saved.Contains(id)));
    }

    // --- Lógica pura testável (portada do 1.0) ---

    // Preço grande: sem decimais. Médio: 2 casas. Sub-dólar: 4 casas.
    public static string FormatUsd(double v) =>
        v >= 100 ? "$" + v.ToString("N0", CultureInfo.InvariantCulture)
        : v >= 1 ? "$" + v.ToString("0.00", CultureInfo.InvariantCulture)
                 : "$" + v.ToString("0.0000", CultureInfo.InvariantCulture);

    // Selecionados primeiro (na ordem salva), depois o resto na ordem do catálogo.
    public static List<string> OrderCatalog(IReadOnlyList<string> catalogIds, IReadOnlyList<string> savedIds)
    {
        var result = new List<string>();
        foreach (var id in savedIds) if (catalogIds.Contains(id)) result.Add(id);
        foreach (var id in catalogIds) if (!result.Contains(id)) result.Add(id);
        return result;
    }
}
```

```csharp
    // Remove hooks "--claude-hook" de OUTRO executável (Orbit 1.0, ou build antigo em outro
    // caminho): sem isso o mesmo evento chegaria duas vezes ao pipe. Matcher que fica vazio sai.
    private static void RemoveStale(JsonArray matchers, string command)
    {
        for (int i = matchers.Count - 1; i >= 0; i--)
        {
            if (matchers[i] is not JsonObject mObj || mObj["hooks"] is not JsonArray inner) continue;
            for (int j = inner.Count - 1; j >= 0; j--)
            {
                if (inner[j] is JsonObject h && h["command"] is JsonValue v && v.TryGetValue<string>(out var c)
                    && c.EndsWith(" --claude-hook", StringComparison.Ordinal) && c != command)
                    inner.RemoveAt(j);
            }
            if (inner.Count == 0) matchers.RemoveAt(i);
        }
    }
```

```markdown
- **Serviços de fundo** (rodam com a ilha recolhida, por evento) alimentam a pílula via
  `IslandViewModel.SetActivity`: `NowPlayingViewModel` (SMTC), `PomodoroViewModel` (timer só
  rodando) e `ClaudeHookServer` (pipe `OrbitClaudeHooks`; o Claude Code chama
  `Orbit.exe --claude-hook`). Prioridade na pílula: Claude aguardando > Pomodoro > mídia.
- **Alertas** passam sempre por `IslandViewModel.Notify(peek, sound)`: peek na pílula, ou toast
  em tela cheia se `AlertsAsToastInFullscreen`.
- **Settings** é uma instância única (`IslandViewModel` repassa às abas): nunca faça
  `SettingsStore.Load()` dentro de aba — o próximo `Save` de outra aba sobrescreveria.
```
