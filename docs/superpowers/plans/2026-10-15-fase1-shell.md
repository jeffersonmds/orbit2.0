# Orbit 2.0 — Fase 1 (Shell) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Uma ilha WPF no topo central da tela: pílula vazia em repouso, estados Atividade/Alerta/Expandida/Oculta com animação, some em tela cheia, painel com abas Energia e Ajustes, bandeja, hotkey e acento do Windows.

**Architecture:** Um processo WPF .NET 10 com MVVM sem DI. A lógica de estados (`IslandMachine`), geometria, acento e decisões de energia são classes/métodos estáticos puros testados num harness próprio (`Orbit.Tests`, exe com `Check(nome, bool)`). A `IslandWindow` tem tamanho fixo 760×400, transparente; só a `Border` "Pill" anima largura/altura. Spec: `docs/superpowers/specs/2026-10-15-orbit2-design.md`.

**Tech Stack:** .NET 10 (`net10.0-windows10.0.17763.0`), WPF + WinForms (só `NotifyIcon`), CommunityToolkit.Mvvm 8.4.1, Serilog 4.3.1 + Serilog.Sinks.File 7.0.0, WinRT `UISettings` (acento), Win32 P/Invoke (appbar, hotkey, energia).

**Convenções (iguais ao Orbit 1.0):** código, comentários e commits em português; `ImplicitUsings` desligado (todo arquivo declara seus `using`); `Nullable` ligado; `[ObservableProperty]` no estilo campo (`private string _x;`); comentários `// ponytail:` marcam simplificações deliberadas.

**Smart App Control:** nesta máquina o SAC às vezes bloqueia um build local do próprio `Orbit.dll` (`FileLoadException ... 0x800711C7`). Se acontecer, rode `dotnet build` de novo (novo hash) e repita — não é bug do código.

**Rodar testes:** `cd /c/repos/orbit2.0 && dotnet run --project Orbit.Tests` → imprime `PASS`/`FAIL` por check e termina com `TODOS OK` (exit 0) ou `N FALHA(S)` (exit 1). Não há filtro por teste.

```csharp
using System;
using System.IO;
using System.Text.Json;
using Orbit.Models;

namespace Orbit.Services;

public static class SettingsStore
{
    // Pasta própria do 2.0 — convive com o %AppData%\Orbit do 1.0.
    public static readonly string Dir =
        Path.Combine(Environment.GetFolderPath(Environment.SpecialFolder.ApplicationData), "Orbit2");

    public static readonly string FilePath = Path.Combine(Dir, "settings.json");
    public static readonly string LogsDir = Path.Combine(Dir, "logs");

    private static readonly JsonSerializerOptions WriteOptions = new() { WriteIndented = true };

    // path só é passado pelos testes; o app usa sempre FilePath.
    public static OrbitSettings Load(string? path = null)
    {
        try
        {
            var p = path ?? FilePath;
            if (!File.Exists(p)) return new OrbitSettings();
            return JsonSerializer.Deserialize<OrbitSettings>(File.ReadAllText(p)) ?? new OrbitSettings();
        }
        catch
        {
            return new OrbitSettings(); // faltando/corrompido/I/O → defaults
        }
    }

    public static void Save(OrbitSettings s, string? path = null)
    {
        try
        {
            var p = path ?? FilePath;
            Directory.CreateDirectory(Path.GetDirectoryName(p)!);
            File.WriteAllText(p, JsonSerializer.Serialize(s, WriteOptions));
        }
        catch
        {
            // disco cheio / sem permissão: não vale crashar a ilha por causa de settings.
        }
    }
}
```

```csharp
using System.Collections.Generic;
using System.Linq;

namespace Orbit.Island;

public enum IslandMode { Repouso, Atividade, Alerta, Expandida, Oculta }

// Valor maior = prioridade maior na pílula.
public enum ActivityKind { Midia = 0, Pomodoro = 1, Claude = 2 }

// Evento pontual que a pílula mostra por alguns segundos. TabId = aba aberta ao clicar.
public sealed record Peek(string Title, string? Detail, string? TabId);

// Lógica pura dos estados da ilha (sem WPF) — testada no harness.
public sealed class IslandMachine
{
    private readonly Dictionary<ActivityKind, string> _activities = new();
    private readonly List<Peek> _pending = new();

    public bool Expanded { get; private set; }
    public bool Fullscreen { get; private set; }
    public Peek? CurrentPeek { get; private set; }

    public IslandMode Mode =>
        Fullscreen ? IslandMode.Oculta
        : Expanded ? IslandMode.Expandida
        : CurrentPeek is not null ? IslandMode.Alerta
        : _activities.Count > 0 ? IslandMode.Atividade
        : IslandMode.Repouso;

    public string? ActivityText =>
        _activities.Count == 0 ? null : _activities.MaxBy(kv => kv.Key).Value;

    public void Expand()
    {
        if (!Fullscreen) Expanded = true;
    }

    public void Collapse() => Expanded = false;

    public void SetFullscreen(bool on)
    {
        Fullscreen = on;
        if (on)
        {
            Expanded = false;
            // Alerta interrompido volta pra frente da fila e reaparece ao sair da tela cheia.
            if (CurrentPeek is not null)
            {
                _pending.Insert(0, CurrentPeek);
                CurrentPeek = null;
            }
        }
        else
        {
            ShowNextPeek();
        }
    }

    // text null/vazio remove a atividade daquele tipo.
    public void SetActivity(ActivityKind kind, string? text)
    {
        if (string.IsNullOrEmpty(text)) _activities.Remove(kind);
        else _activities[kind] = text;
    }

    public void RaisePeek(Peek peek)
    {
        _pending.Add(peek);
        if (!Fullscreen) ShowNextPeek();
    }

    public void PeekDone()
    {
        CurrentPeek = null;
        if (!Fullscreen) ShowNextPeek();
    }

    private void ShowNextPeek()
    {
        if (CurrentPeek is not null || _pending.Count == 0) return;
        CurrentPeek = _pending[0];
        _pending.RemoveAt(0);
    }
}
```

```csharp
using System;

namespace Orbit.Island;

public readonly record struct IslandSize(double Width, double Height);

// Tamanhos em DIPs. A janela é fixa; só a pílula anima até estes tamanhos.
public static class IslandGeometry
{
    public const double WindowWidth = 760;
    public const double WindowHeight = 400;

    public static IslandSize SizeFor(IslandMode mode) => mode switch
    {
        IslandMode.Atividade => new IslandSize(320, 30),
        IslandMode.Alerta => new IslandSize(360, 56),
        IslandMode.Expandida => new IslandSize(720, 380),
        _ => new IslandSize(110, 10), // Repouso e Oculta
    };

    // Raio dos cantos de baixo (os de cima encostam na borda da tela).
    public static double RadiusFor(IslandMode mode) => mode switch
    {
        IslandMode.Expandida => 22,
        IslandMode.Alerta => 18,
        IslandMode.Atividade => 15,
        _ => 5,
    };

    public static double LeftFor(double screenWidth) => Math.Round((screenWidth - WindowWidth) / 2);
}
```

```csharp
    // Guardado em campo: se o UISettings for coletado, o evento ColorValuesChanged para.
    private static UISettings? _ui;
    private static Func<string?> _override = () => null;

    public static Color? ParseHex(string? hex)
    {
        if (hex is null || !HexRx.IsMatch(hex)) return null;
        byte B(int i) => byte.Parse(hex.AsSpan(i, 2), NumberStyles.HexNumber);
        return Color.FromRgb(B(1), B(3), B(5));
    }

    public static Color Resolve(string? overrideHex, Color system) => ParseHex(overrideHex) ?? system;

    public static Color Soft(Color c) => Color.FromArgb(0x33, c.R, c.G, c.B);

    public static Color ReadSystem()
    {
        try
        {
            var c = (_ui ?? new UISettings()).GetColorValue(UIColorType.Accent);
            return Color.FromRgb(c.R, c.G, c.B);
        }
        catch (Exception ex)
        {
            Log.Warning(ex, "Não consegui ler a cor de destaque do Windows");
            return Fallback;
        }
    }

    // Chamado uma vez no startup. overrideHex é lido a cada Refresh (Ajustes muda o valor).
    public static void Start(Func<string?> overrideHex)
    {
        _override = overrideHex;
        try
        {
            _ui = new UISettings();
            // O evento vem de outra thread — volta pro dispatcher antes de mexer nos recursos.
            _ui.ColorValuesChanged += (_, _) => Application.Current?.Dispatcher.BeginInvoke(Refresh);
        }
        catch (Exception ex)
        {
            Log.Warning(ex, "UISettings indisponível; acento não acompanhará o Windows");
        }
        Refresh();
    }

    public static void Refresh()
    {
        var c = Resolve(_override(), ReadSystem());
        var res = Application.Current.Resources;
        res["AccentBrush"] = Frozen(c);
        res["AccentSoftBrush"] = Frozen(Soft(c));
    }

    private static SolidColorBrush Frozen(Color c)
    {
        var b = new SolidColorBrush(c);
        b.Freeze();
        return b;
    }
```

```csharp
using System.Diagnostics;
using System.Runtime.InteropServices;

namespace Orbit.Services;

public enum PowerAction { Bloquear, Suspender, Reiniciar, Desligar }

// Ações de energia. Usado pela aba Energia e, na fase 4, pelos endpoints /power/* da ponte.
public static class Power
{
    public static bool NeedsConfirmation(PowerAction action) =>
        action is PowerAction.Reiniciar or PowerAction.Desligar;

    public static string? ShutdownArgs(PowerAction action) => action switch
    {
        PowerAction.Reiniciar => "/r /t 0",
        PowerAction.Desligar => "/s /t 0",
        _ => null,
    };

    public static void Execute(PowerAction action)
    {
        switch (action)
        {
            case PowerAction.Bloquear:
                LockWorkStation();
                break;
            case PowerAction.Suspender:
                SetSuspendState(hibernate: false, forceCritical: false, disableWakeEvent: false);
                break;
            default:
                Process.Start(new ProcessStartInfo("shutdown", ShutdownArgs(action)!)
                {
                    CreateNoWindow = true,
                    UseShellExecute = false,
                });
                break;
        }
    }

    [DllImport("user32.dll", SetLastError = true)]
    private static extern bool LockWorkStation();

    [DllImport("powrprof.dll", SetLastError = true)]
    private static extern bool SetSuspendState(bool hibernate, bool forceCritical, bool disableWakeEvent);
```

```csharp
using System;
using System.Runtime.InteropServices;
using System.Text;
using System.Windows.Interop;

namespace Orbit.Island;

// Registra a janela como appbar (ABM_NEW, sem ABM_SETPOS → não reserva espaço na tela)
// só pra receber ABN_FULLSCREENAPP do shell. Zero polling.
public sealed class FullscreenWatcher : IDisposable
{
    private const uint ABM_NEW = 0, ABM_REMOVE = 1;
    private const int ABN_FULLSCREENAPP = 2;
    private const uint MONITOR_DEFAULTTONEAREST = 2;

    private readonly IntPtr _hwnd;
    private readonly HwndSource _source;
    private readonly uint _callbackMsg;

    public event Action<bool>? Changed;

    public FullscreenWatcher(IntPtr hwnd)
    {
        _hwnd = hwnd;
        _callbackMsg = RegisterWindowMessage("Orbit2.AppBar");
        _source = HwndSource.FromHwnd(hwnd)!;
        _source.AddHook(WndProc);
        var data = NewData();
        SHAppBarMessage(ABM_NEW, ref data);
    }

    // O shell também avisa "tela cheia" quando a área de trabalho/barra ganha foco,
    // e quando o app está em outro monitor — os dois casos não devem esconder a ilha.
    public static bool ShouldHide(bool shellSaysFullscreen, string foregroundClass, bool sameMonitor) =>
        shellSaysFullscreen && sameMonitor &&
        foregroundClass is not ("Progman" or "WorkerW" or "Shell_TrayWnd");

    private IntPtr WndProc(IntPtr hwnd, int msg, IntPtr wParam, IntPtr lParam, ref bool handled)
    {
        if (msg == (int)_callbackMsg && wParam.ToInt32() == ABN_FULLSCREENAPP)
        {
            var fg = GetForegroundWindow();
            var cls = new StringBuilder(256);
            GetClassName(fg, cls, cls.Capacity);
            bool same = MonitorFromWindow(fg, MONITOR_DEFAULTTONEAREST) == MonitorFromWindow(_hwnd, MONITOR_DEFAULTTONEAREST);
            Changed?.Invoke(ShouldHide(lParam != IntPtr.Zero, cls.ToString(), same));
            handled = true;
        }
        return IntPtr.Zero;
    }

    private APPBARDATA NewData() => new()
    {
        cbSize = Marshal.SizeOf<APPBARDATA>(),
        hWnd = _hwnd,
        uCallbackMessage = _callbackMsg,
    };

    public void Dispose()
    {
        _source.RemoveHook(WndProc);
        var data = NewData();
        SHAppBarMessage(ABM_REMOVE, ref data);
    }

    [StructLayout(LayoutKind.Sequential)]
    private struct RECT { public int Left, Top, Right, Bottom; }

    [StructLayout(LayoutKind.Sequential)]
    private struct APPBARDATA
    {
        public int cbSize;
        public IntPtr hWnd;
        public uint uCallbackMessage;
        public uint uEdge;
        public RECT rc;
        public IntPtr lParam;
    }

    [DllImport("shell32.dll")] private static extern UIntPtr SHAppBarMessage(uint dwMessage, ref APPBARDATA pData);
    [DllImport("user32.dll", CharSet = CharSet.Unicode)] private static extern uint RegisterWindowMessage(string lpString);
    [DllImport("user32.dll")] private static extern IntPtr GetForegroundWindow();
    [DllImport("user32.dll", CharSet = CharSet.Unicode)] private static extern int GetClassName(IntPtr hWnd, StringBuilder lpClassName, int nMaxCount);
    [DllImport("user32.dll")] private static extern IntPtr MonitorFromWindow(IntPtr hwnd, uint dwFlags);
}
```

```csharp
    private const uint VK_O = 0x4F;
    private const int Id = 0xB0C;

    public GlobalHotKey(IntPtr hwnd)
    {
```

```csharp
    [ObservableProperty] private IslandMode _mode = IslandMode.Repouso;
    [ObservableProperty] private string _activityText = "";
    [ObservableProperty] private Peek? _peek;

    public IslandViewModel(OrbitSettings settings)
    {
        _settings = settings;
        // Sem DI: cada aba é criada aqui na mão (fases 2-4 acrescentam as outras).
        Tabs = new ObservableCollection<TabViewModel>
        {
            new EnergiaViewModel(),
            new AjustesViewModel(settings),
        };
        SelectedTab = Tabs.FirstOrDefault(t => t.Id == settings.LastTab) ?? Tabs[0];
    }

    partial void OnSelectedTabChanged(TabViewModel? oldValue, TabViewModel? newValue)
    {
        if (Mode == IslandMode.Expandida)
        {
            SafeSetActive(oldValue, false);
            SafeSetActive(newValue, true);
        }
        if (newValue is not null && newValue.Id != _settings.LastTab)
        {
            _settings.LastTab = newValue.Id;
            SettingsStore.Save(_settings);
        }
    }

    public void Expand() { _machine.Expand(); Refresh(); }
    public void Collapse() { _machine.Collapse(); Refresh(); }
    public void SetFullscreen(bool on) { _machine.SetFullscreen(on); Refresh(); }
    public void SetActivity(ActivityKind kind, string? text) { _machine.SetActivity(kind, text); Refresh(); }
    public void RaisePeek(Peek peek) { _machine.RaisePeek(peek); Refresh(); }
    public void PeekExpired() { _machine.PeekDone(); Refresh(); }

    public void OpenTab(string id)
    {
        var tab = Tabs.FirstOrDefault(t => t.Id == id);
        if (tab is not null) SelectedTab = tab;
        Expand();
    }

    // Clique no alerta: consome o alerta e abre a aba relacionada (ou só expande).
    public void OpenPeekTab()
    {
        var tabId = _machine.CurrentPeek?.TabId;
        _machine.PeekDone();
        if (tabId is null) Expand();
        else OpenTab(tabId);
    }

    private void Refresh()
    {
        var before = Mode;
        ActivityText = _machine.ActivityText ?? "";
        Peek = _machine.CurrentPeek;
        Mode = _machine.Mode; // por último: a janela reage a Mode e já lê Peek/ActivityText novos
        if (before != IslandMode.Expandida && Mode == IslandMode.Expandida) SafeSetActive(SelectedTab, true);
        if (before == IslandMode.Expandida && Mode != IslandMode.Expandida) SafeSetActive(SelectedTab, false);
    }

    // Uma aba quebrada não pode derrubar a ilha.
    public static void SafeSetActive(TabViewModel? tab, bool active)
    {
        if (tab is null) return;
        try
        {
            tab.SetActive(active);
        }
        catch (Exception ex)
        {
            Log.Error(ex, "Aba {Tab} falhou em SetActive({Active})", tab.Id, active);
        }
    }
}
```

```csharp
using System;
using System.Runtime.InteropServices;
using System.Windows;
using System.Windows.Input;
using System.Windows.Interop;
using System.Windows.Media.Animation;
using System.Windows.Threading;
using Orbit.Services;

namespace Orbit.Island;

public partial class IslandWindow : Window
{
    private readonly IslandViewModel _vm;
    private readonly TrayIcon _tray;
    private readonly DispatcherTimer _hover = new() { Interval = TimeSpan.FromMilliseconds(250) };
    private readonly DispatcherTimer _leave = new() { Interval = TimeSpan.FromMilliseconds(600) };
    private readonly DispatcherTimer _peek = new() { Interval = TimeSpan.FromSeconds(4) };
    private GlobalHotKey? _hotKey;
    private FullscreenWatcher? _fullscreen;
    private bool _userHidden;
#if DEBUG
    private bool _debugActivity;
#endif

    public IslandWindow(IslandViewModel vm)
    {
        InitializeComponent();
        _vm = vm;
        DataContext = vm;
        Left = IslandGeometry.LeftFor(SystemParameters.PrimaryScreenWidth);
        Top = 0;

        _hover.Tick += (_, _) => { _hover.Stop(); _vm.Expand(); };
        _leave.Tick += (_, _) => { _leave.Stop(); _vm.Collapse(); };
        _peek.Tick += (_, _) => { _peek.Stop(); _vm.PeekExpired(); };
        _vm.PropertyChanged += (_, e) =>
        {
            if (e.PropertyName == nameof(IslandViewModel.Mode)) OnModeChanged();
        };

        _tray = new TrayIcon();
        _tray.ToggleVisibility += () => { _userHidden = !_userHidden; UpdateVisibility(); };
        _tray.SettingsRequested += () => { _userHidden = false; UpdateVisibility(); _vm.OpenTab("ajustes"); Activate(); };
        _tray.ExitRequested += () => Application.Current.Shutdown();
#if DEBUG
        _tray.DebugPeek += () => _vm.RaisePeek(new Peek("Alerta de teste", "github.com/… · abrindo no navegador", "energia"));
        _tray.DebugActivity += () =>
        {
            _debugActivity = !_debugActivity;
            _vm.SetActivity(ActivityKind.Midia, _debugActivity ? "▶  lofi beats · lofi radio" : null);
        };
#endif

        ApplyLayout(_vm.Mode, animate: false);
    }

    protected override void OnSourceInitialized(EventArgs e)
    {
        base.OnSourceInitialized(e);
        var hwnd = new WindowInteropHelper(this).Handle;

        // WS_EX_TOOLWINDOW: fora do Alt+Tab.
        SetWindowLong(hwnd, GWL_EXSTYLE, GetWindowLong(hwnd, GWL_EXSTYLE) | WS_EX_TOOLWINDOW);

        _hotKey = new GlobalHotKey(hwnd);
        _hotKey.Pressed += () =>
        {
            if (_vm.Mode == IslandMode.Expandida) _vm.Collapse();
            else ExpandFocused();
        };

        _fullscreen = new FullscreenWatcher(hwnd);
        _fullscreen.Changed += on => _vm.SetFullscreen(on);
    }

    protected override void OnClosed(EventArgs e)
    {
        _hotKey?.Dispose();
        _fullscreen?.Dispose();
        _tray.Dispose();
        base.OnClosed(e);
    }

    private void OnModeChanged()
    {
        var mode = _vm.Mode;
        if (mode == IslandMode.Alerta) _peek.Start();
        else _peek.Stop();
        UpdateVisibility();
        ApplyLayout(mode, animate: true);
    }

    // Abertura intencional (hotkey/clique) pega o foco pra Esc e "clique fora" funcionarem.
    // Hover NÃO ativa: encostar o mouse no topo não pode roubar o foco de quem está digitando.
    private void ExpandFocused()
    {
        _vm.Expand();
        Activate();
    }

    private void UpdateVisibility() =>
        Visibility = _userHidden || _vm.Mode == IslandMode.Oculta ? Visibility.Hidden : Visibility.Visible;

    // Anima a pílula até o tamanho do estado e só então revela a camada de conteúdo.
    private void ApplyLayout(IslandMode mode, bool animate)
    {
        var size = IslandGeometry.SizeFor(mode);
        var r = IslandGeometry.RadiusFor(mode);
        Pill.CornerRadius = new CornerRadius(0, 0, r, r);

        ActivityLayer.Visibility = Visibility.Collapsed;
        PeekLayer.Visibility = Visibility.Collapsed;
        ExpandedLayer.Visibility = Visibility.Collapsed;
        UIElement? layer = mode switch
        {
            IslandMode.Atividade => ActivityLayer,
            IslandMode.Alerta => PeekLayer,
            IslandMode.Expandida => ExpandedLayer,
            _ => null,
        };

        if (!animate)
        {
            Pill.BeginAnimation(WidthProperty, null);
            Pill.BeginAnimation(HeightProperty, null);
            Pill.Width = size.Width;
            Pill.Height = size.Height;
            if (layer is not null) layer.Visibility = Visibility.Visible;
            return;
        }

        bool growing = size.Width * size.Height > Pill.ActualWidth * Pill.ActualHeight;
        IEasingFunction ease = growing
            ? new BackEase { Amplitude = 0.3, EasingMode = EasingMode.EaseOut }
            : new CubicEase { EasingMode = EasingMode.EaseInOut };
        var duration = TimeSpan.FromMilliseconds(growing ? 320 : 220);

        var w = new DoubleAnimation(size.Width, duration) { EasingFunction = ease };
        var h = new DoubleAnimation(size.Height, duration) { EasingFunction = ease };
        if (layer is not null)
            h.Completed += (_, _) => { if (_vm.Mode == mode) FadeIn(layer); };

        Pill.BeginAnimation(WidthProperty, w);
        Pill.BeginAnimation(HeightProperty, h);
    }

    private static void FadeIn(UIElement element)
    {
        element.Visibility = Visibility.Visible;
        element.BeginAnimation(OpacityProperty, new DoubleAnimation(0, 1, TimeSpan.FromMilliseconds(140)));
    }

    private void OnPillEnter(object sender, MouseEventArgs e)
    {
        _leave.Stop();
        if (_vm.Mode != IslandMode.Expandida) _hover.Start();
    }

    private void OnPillLeave(object sender, MouseEventArgs e)
    {
        _hover.Stop();
        if (_vm.Mode == IslandMode.Expandida) _leave.Start();
    }

    private void OnPillWheel(object sender, MouseWheelEventArgs e)
    {
        if (e.Delta >= 0 || _vm.Mode == IslandMode.Expandida) return;
        _hover.Stop();
        _vm.Expand();
    }

    private void OnPillClick(object sender, MouseButtonEventArgs e)
    {
        if (_vm.Mode == IslandMode.Alerta) { _vm.OpenPeekTab(); Activate(); }
        else if (_vm.Mode != IslandMode.Expandida) ExpandFocused();
    }

    private void OnKeyDown(object sender, KeyEventArgs e)
    {
        if (e.Key == Key.Escape) _vm.Collapse();
    }

    private void OnDeactivated(object? sender, EventArgs e) => _vm.Collapse();

    private const int GWL_EXSTYLE = -20;
    private const int WS_EX_TOOLWINDOW = 0x00000080;
    [DllImport("user32.dll")] private static extern int GetWindowLong(IntPtr hWnd, int nIndex);
    [DllImport("user32.dll")] private static extern int SetWindowLong(IntPtr hWnd, int nIndex, int dwNewLong);
}
```

````markdown
# CLAUDE.md

## O que é

Orbit 2.0: uma "ilha" estilo Dynamic Island (inspirada no Hitodama) no topo central da tela do
Windows. WPF .NET 10. Em repouso é uma pílula vazia; expande para um painel com abas. Spec:
`docs/superpowers/specs/2026-10-15-orbit2-design.md`. Sucessor do Orbit 1.0 (`C:\repos\orbit1.0`).

Código, comentários e commits são em **português**.

## Comandos

```bash
dotnet build                              # app + testes (Orbit.slnx)
dotnet run --project Orbit                # roda a ilha
dotnet run --project Orbit.Tests          # roda TODOS os testes; exit != 0 se falhar
```

`Orbit.Tests` é um exe com harness próprio (`Check(nome, bool)`), sem xUnit. Só testa métodos
puros/estáticos: extraia a lógica para `static` sem I/O nem UI e registre um `Check`.

Smart App Control está ligado nesta máquina: se um build local der `FileLoadException 0x800711C7`,
rebuild (novo hash) e tente de novo. Evite pacotes NuGet com DLL nativa de terceiro.

## Arquitetura

- **Uma janela fixa** (`Island/IslandWindow`, 760×400, transparente, topmost). Só a `Border`
  "Pill" anima; pixels alpha 0 deixam o clique passar.
- **`IslandMachine`** (puro) decide o estado: Repouso, Atividade, Alerta, Expandida, Oculta.
  `IslandViewModel` orquestra a máquina e as abas; a janela só reage a `Mode`.
- **Abas** herdam `Tabs/TabViewModel` e ficam em `Tabs/<Nome>/`. São criadas na mão no
  construtor de `IslandViewModel` (sem DI). **Contrato de leveza:** só a aba visível do painel
  expandido recebe `SetActive(true)`; timers e fetches só rodam ativos. `SafeSetActive` isola exceções.
- **Tela cheia:** `FullscreenWatcher` (appbar + `ABN_FULLSCREENAPP`) esconde a ilha.
- **Acento:** `Services/Accent` usa a cor de destaque do Windows (`UISettings`) ou o override
  de Ajustes; recursos `AccentBrush`/`AccentSoftBrush` — sempre `DynamicResource`.
- **Settings:** `%AppData%\Orbit2\settings.json`; `Load()` nunca lança, `Save()` engole I/O.
  Logs Serilog em `%AppData%\Orbit2\logs\`.
- Hotkey global: Ctrl+Alt+O. Instância única: mutex `Orbit2_SingleInstance`.

## Convenções

- `ImplicitUsings` desligado; `Nullable` ligado; `[ObservableProperty]` no estilo campo.
- `// ponytail:` marca simplificação deliberada com teto conhecido — respeite.
````
